# Изображения темы

Все картинки лежат в одной папке, без подпапок — так их ищет `alfa_image()`.

## Правила

- **`.png`** — оригинал (из Figma / от фотографа), не отдаётся браузеру.
- **`.webp`** — рабочая версия, её и отдаёт `alfa_image()` (см. `functions.php`): если рядом с `.png` есть `.webp`, подставляется он.
- Если файла нет — `alfa_image()` берёт `fallback`, а если и его нет — `f-2018-8635.png`.
- Имена осмысленные (`hero-bg`, `coop-portrait`, `payment-*`); оставшиеся `f-2018-*` / `f-2020-*` — это фотографии со съёмки, они переиспользуются в кейсах, услугах и фотогалерее.

## Что где используется

| Файл | Где |
|---|---|
| `hero-bg` | фон первого экрана (`front-page.php`) |
| `case-cover` | обложки кейсов, дефолт в `cases-grid.php` |
| `f-2018-8635`, `8643`, `8654`, `8656`, `8658`, `8673` | промо-ролики, услуги, блог, квиз |
| `f-2018-9023`, `9024`, `9033`, `9034`, `9035`, `9036` | фотогалерея «Встречи с клиентами» |
| `f-2020-9608`, `9619` | строки услуг |
| `coop-portrait` | портрет в блоке «Сотрудничество» |
| `owner-portrait` | резервный портрет (fallback) |
| `callback-bg`, `callback-portrait`, `callback-face`, `callback-pin` | блок заявки |
| `review-poster` | постер видео-отзывов (кадр с текстом) |
| `avatar-manager` | аватар в шапке |
| `footer-qr`, `payment-mtbank`, `payment-systems` | подвал: QR и логотипы оплаты |
| `page-status` | страницы 404 и «в разработке» |

## Чего не хватает

Шесть кадров со съёмки так и не выгрузились из Figma. Они прописаны в коде как основные, а пока показываются соседние фото через `fallback`:

`f-2018-9035.png`, `f-2018-9036.png`, `f-2020-9398.png`, `f-2020-9407.png`, `f-2020-9416.png`, `f-2020-9425.png`

Достаточно положить файлы в эту папку (можно сразу `.webp`) — тема подхватит их автоматически, код менять не нужно.

## Пересобрать WebP

```bash
python3 - <<'PY'
from PIL import Image
import glob
for f in glob.glob('assets/images/*.png'):
    Image.open(f).convert('RGB').save(f.replace('.png', '.webp'), 'WEBP', quality=85, method=6)
PY
```

## Как это устроено

- **Контейнер**: 1920 px макет, контент 1850 px (`--container`), отступы 35 px.
- **Типографика**: Stengazeta (заголовки, только капс), Raleway (текст, variable 100–900), Montserrat (лого, ТОП-3, доли).
- **Палитра**: фон `#363940`, акцент `#5DAEBE`, градиент кнопок `#66838C → #336676`.
- **Кнопки**: `.btn--primary` (градиент), `.btn--ghost` (обводка), `.btn--sm`.
- Все размеры шрифтов — через `clamp()`, поэтому вёрстка тянется от 360 до 2560 px.

## Контент

- **Кейсы** — тип записи `alfa_case`, URL `/keysy/<slug>/`. У каждого кейса в админке есть метабокс «Этапы и результаты кейса» (4 шага + 3 метрики); пустые поля → показываются дефолтные значения.
- **Заявки** — попадают в раздел «Заявки» (тип `alfa_lead`, приватные). Обработчик — AJAX `alfa_lead`, с nonce, проверкой телефона и санитайзом.
- **Меню** — `primary` (шапка) и `footer`. Если меню не задано, работает фолбэк на основные страницы.
- **Страницы уже созданы**: Главная, Услуги, О нас, Кейсы, Блог, Вакансии, Спасибо, Квиз, В разработке, Видео-блог.

## Картинки

Все изображения лежат в `assets/images/` в двух форматах: `.webp` (используется) и `.png` (оригинал). Хелпер `alfa_image()` в `functions.php` отдаёт `.webp`, если он есть, иначе `.png`, а если нет ни того, ни другого — подставляет безопасную замену, чтобы на странице не было битых картинок. Подробная карта файлов — в `assets/images/README.md`.

Пересобрать WebP после замены PNG:

```bash
python3 - <<'PY'
from PIL import Image
import glob
for f in glob.glob('assets/images/*.png'):
    Image.open(f).convert('RGB').save(f.replace('.png', '.webp'), 'WEBP', quality=85, method=6)
PY
```

## Что осталось

Шесть кадров с фотосессии не выгрузились из Figma (эндпоинт рендера отдавал `429 Rate limit exceeded`). В коде они прописаны как основные, а пока показываются соседние фото через `fallback`:

`f-2018-9035.png`, `f-2018-9036.png`, `f-2020-9398.png`, `f-2020-9407.png`, `f-2020-9416.png`, `f-2020-9425.png`

Достаточно положить их в `assets/images/` (PNG или сразу WebP) — тема подхватит автоматически, ничего в коде менять не нужно.

Тексты вакансий, 404, «спасибо» и квиза — авторские формулировки, в макете на их месте рыба.
